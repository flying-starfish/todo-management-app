# 本番化チェックリスト

## セキュリティ

- 強力な `SECRET_KEY` を設定
- `ENVIRONMENT=production` を使用
- CORS 設定を本番ドメインに限定
- HTTPS 終端とセキュリティヘッダーを確認

## データベース

- PostgreSQL 接続文字列を確認
- マイグレーション手順を確認
- バックアップ手順を用意

## アプリ設定

- ログレベルを `INFO` 以上に設定
- `.env.production` を整理
- ヘルスチェックエンドポイントを確認

## CI/CD

- テスト・Lint・型チェック・脆弱性スキャンが通る
- Docker イメージがビルド可能
- デプロイ先の環境変数が定義済み

## リリース前の最終確認

- 新規登録・ログイン・Todo CRUD の動作確認
- フロントから API への接続確認
- 監視ログの確認
